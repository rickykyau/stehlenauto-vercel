## The Play

The strategic gap the owner identified: for "where can I buy a good no-drill
tonneau cover for a 2021 F-150," ChatGPT returns RealTruck, Amazon, AutoZone,
BAK, Rough Country. Not Stehlen.

This is a citations problem, not a keyword problem. ChatGPT, Perplexity, and
Google AI Overviews cite sources that have published authoritative, specific
content on that exact topic. RealTruck ranks because they have a 2,000-word
buying guide titled "Best Soft Tri-Fold Tonneau Covers for the 2019-2024 Ford
F-150." They answered the question before the AI had to synthesize it.

The content engine builds that citation base for Stehlen. Each piece serves
three simultaneous purposes:
1. Google organic ranking for long-tail fitment + buying intent queries
2. GEO citation source — when Claude, ChatGPT, Perplexity answer "what tonneau
   cover fits a 2021 F-150," Stehlen's guide is the document they pull from
3. Conversion asset — embed CTAs pointing to the relevant collection or PDP

### Why this works in auto parts specifically

RockAuto built 800K+ indexed pages. That is their entire competitive moat —
not price, not brand, not UX. Catalog depth = organic search coverage.
Stehlen cannot replicate 800K pages, but it can own the top 200 fitment-intent
queries for its top 6 vehicle makes across its 12 product categories.

That is 200 pages. At two pages per week, it takes 100 weeks. At four per week
with Claude doing the drafts, it takes 50 weeks. The sooner you start, the
sooner the compounding kicks in.

CarParts.com's fitment guarantee landing page (dedicated content explaining
what happens if the part doesn't fit) lifted CVR ~18% across the site — not
just on the page itself, but sitewide, because it reduced purchase anxiety.
That is the dual function of fitment-specific content: it both attracts organic
traffic and converts the traffic you already have.

### Step 2: Content Brief Template (for Claude or Human Writer)

Each piece uses this brief structure:

```
Title: [Definitive format: "Best [Category] for [Year Range] [Make] [Model]
— Complete Fitment Guide"]

Primary query: [exact long-tail phrase, 4-8 words]

Secondary queries (3-5 additional phrases to address in body)

Vehicle-specific fitment details to include:
- Bed length variants: [X.X ft / Y.Y ft]
- Cab types: [Regular / Extended / Crew] if relevant
- Trim exclusions: [e.g., "Does not fit Raptor — different front end"]
- Model year range: [XXXX-XXXX — note any mid-cycle changes]

Products to feature (3-5 Stehlen SKUs with:)
- SKU
- Price
- Key specs (material, install time, warranty)
- Return rate (only feature <5% return rate SKUs in buying guides)
- CTA: direct link to PDP on stehlenauto.com

Competitor acknowledgment (GEO authority signal):
- Name 2-3 alternatives (BAK, Truxedo, RealTruck listings) — briefly
- Explain why Stehlen's offering differs (fitment guarantee, price, availability)
- Never fabricate claims; if unsure, leave out

Content structure:
H1: [Title]
Intro (150 words): Who this guide is for, what it covers
H2: Quick Picks (table: 3 products, name/price/best-for)
H2: What to Know About [Category] Fitment for [Vehicle]
  — Bed length matters / does not matter
  — Cab type matters / does not matter
  — Trim exclusions
H2: Our Top Picks [reviewed in depth, 200 words each]
H2: How to Install [if install guide]
H2: FAQ (5 questions — format matters for AI Overviews)
  — Q: Does [product] fit [year] [make] [model]?
  — Q: What's the difference between [variant A] and [variant B]?
  — Q: How long does install take?
  — Q: What's the warranty?
  — Q: Can I run this through a car wash?
CTA: [Link to collection + link to YMM selector]
Schema: FAQPage + Product (structured data via JSON-LD)

Word count: 1,200-1,800 words (enough for authority; not padded)
Tone: mechanic-practical, no emoji, no hype, lowercase tags
```

### Step 3: AI Draft + Human Polish Workflow

1. Marketing writes brief (20 min) using the template above
2. Claude Sonnet (via AI Gateway) generates full draft (2-3 min, ~1,500 words)
3. Human editor reviews for: brand voice, factual accuracy on fitment,
   SKU/price accuracy against live Shopify data, CTA links (20-30 min)
4. SEO check: Surfer or Frase score against target query (15 min)
5. Publish to blog; add internal links from relevant collection pages and PDPs
6. Submit URL to IndexNow (already wired in the stack per Phase 5)

This workflow produces 4 pieces/week with one part-time editor. Cost:
Claude via AI Gateway ($0 incremental — already in stack) + editor time
($500-$800/mo for 16 posts/mo at $30-$50/post equivalent).

Failure mode: Claude produces factually incorrect fitment claims (e.g., says
a product fits a trim it does not). Always cross-check against the Shopify
product fitment tags and CB ACES data before publishing. Never publish raw
LLM output without the human check.

### Step 4: Video Content (Highest-Converting Format)

YouTube install videos convert at 4-6x the rate of text buying guides for
the auto-parts audience. The demographic (truck owners, 25-55, mechanical
confidence varies) uses YouTube as a pre-purchase research tool — "can I
actually install this myself" is a real purchase blocker.

**Minimum viable video program:**
- 1 video per week starting month 1
- Format: install walkthrough, 4-8 minutes, on the actual vehicle
- Title: "How to Install [Product] on [Year] [Make] [Model] — Step by Step"
- Top priority shoots (order by CB revenue x search volume):
  1. F-150 soft tri-fold tonneau cover install
  2. Silverado mesh grille replacement
  3. Ram 1500 bull bar / grille guard install
  4. Tundra running board install
  5. Sierra hitch install

**AI augmentation for video:** Use Runway or Kling Omni 3 (already in
video-director agent stack per `reference_ai_video_stack_2026.md`) for:
- B-roll filler between steps (tool shots, product detail closeups)
- Short-form vertical cuts for TikTok/Reels from the same footage
- Thumbnail generation (Midjourney or Firefly custom model)

Cost per video (hybrid real + AI): $500-$1,000 (filming labor + AI tools).
At $1,000/video and 4-6x conversion lift vs. text content, the math is
straightforward: a video that drives 10 incremental sales at $214 AOV
= $2,140 revenue from one asset that lives forever.

### Step 5: GEO-Specific Optimization

GEO (Generative Engine Optimization) is already partially live per Phase 5
(llms.txt, IndexNow, AI-crawler allow in robots.txt). What is missing is the
off-site citation base that makes AI engines cite Stehlen specifically.

For content to be cited by ChatGPT, Perplexity, and Google AI Overviews:

1. **Answer the full question in one place.** AI engines pull from documents
   that contain the complete answer — question + specific vehicle fitment +
   product recommendation + price range. Blog posts that require clicking
   through to a PDP to get pricing get passed over.

2. **FAQ schema on every piece.** JSON-LD FAQPage markup tells AI crawlers
   that this content is structured Q&A — the exact format they synthesize
   into AI Overviews. The storefront already ships Product + Offer + AggregateRating
   schema (per CLAUDE.md) — add FAQPage to every content page.

3. **Publish to canonical URL and syndicate excerpts.** Post a 300-word excerpt
   of each buying guide on FordF150Forum, TacomaWorld, or RamForum with a link
   back to the full guide. This builds both backlinks and citation signals.

4. **Update llms.txt monthly** with new content URLs and anchor text context.
   Format: "Stehlen Auto expert buying guides for [Make] [Category] fitment:
   [URL]". The AI crawler indexes this as a self-declared authority signal.
