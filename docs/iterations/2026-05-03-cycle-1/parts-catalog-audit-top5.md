# Parts Catalog Audit — Top 5 Categories (Cycle 3)

**Auditor:** Auto-Parts Specialist (20+ yr veteran — warehouse, install bay, fitment desk, ACES/PIES committee)
**Source:** `docs/iterations/2026-05-03-cycle-1/shopify-storefront-products.csv` (1,322 ACTIVE storefront products)
**Date:** 2026-05-02
**Scope:** Top 5 categories by SKU count = 838 SKUs = 63% of catalog
**Verdict (TL;DR):** Tagging is **better than I expected**, bed-length data is excellent, BUT there is a **P0 multi-generation lie problem in headlights** and a **silent landmine in the "Dodge Ram 6.5 ft" bed mats** (Ram has no 6'5" bed — only 5'7", 6'4", 8'). Catalog is **NOT ready for unfiltered Google Shopping** as-is, but it is fixable in <1 sprint.

## 1. trailer hitch kit

- **Total SKUs:** 257
- **Tagging integrity:** **Pass** — Every row I sampled has structured year-range tags (`year:2017`, `year:2018`...), `make:`, `model:`, `category:Trailer Hitches`, and a class designation. Class breakdown by title: Class 3 = 176, Class 1 = 24, Class 4 = 12, Class 2 = 12, Class 5 = 0. Class V/5 absence is **correct** for Stehlen's vehicle mix (Class V is for diesel HD ¾-ton+ towing 18,000+ lb — that's CURT 15-series territory, not in this catalog). Class III/IV is properly differentiated by both title and class tag.
- **Sub-model gating required:** **none for browsing, drivetrain caveat for install** — receiver hitches bolt to the rear frame, which is generation-stable. **Caveat:** rear-bumper-mounted spare tires (some Wranglers, 4Runners) and HD diesel exhaust packages can interfere — that's a PDP install-note concern, not a fitment gate.
- **Title-vs-tag mismatches found:**
  - `2007-2024-jeep-wrangler-jk-jl-2-trailer-hitch-receiver-class-3` — JK (07-18) vs JL (18-24) is a **legitimate platform-mate continuity for hitches** (rear frame-rail bolt pattern is consistent), but a 2-door JK Sport has different rear frame geometry than 4-door JKU. Tags don't disclose door-count. **Low return risk** because hitch bolts are common, but copy should say "fits both 2-door and 4-door — verify spare tire clearance".
  - `2008-2017-buick-enclave-chevy-traverse-class-3-hitch-kit-curt` — correct platform-mate (Lambda), but spans pre/post 2013 facelift. Hitch is generation-stable, fine.
  - `04-15-nissan-armada-infiniti-qx56-trailer-hitch-kit-curt` — correct platform-mate (Y61/Y62), CURT 13554 is one part across all years. OK.
  - `curt-2-loaded-ball-mount-with-1-7-8-ball-45034` and 2 other "universal" ball-mount/cargo-carrier SKUs miscategorized as `trailer hitch kit` — these are accessories, not hitches. Should live in a `towing accessories` bucket.
  - `universal-2-tube-3-steel-rear-hitch-step-black` and `2-hitch-cargo-carrier-300-lb-tray-style-fold-up-23x59-black` — same problem (Stehlen-branded universals miscategorized).
  - `universal-2-receiver-hitch-step-matte-black-hs207-31bk` — same.
  - `rv-72-adjustable-class-3-trailer-hitch-w-loaded-ball-mount` — universal RV adjustable, no vehicle YMM. Belongs in universal/RV bucket.
- **Install-copy honesty risks at PDP scale:**
  - Hitches on >10-yr-old vehicles in salt regions: factory frame nuts will be seized. "Bolt-on, no drilling" is true; **"30-min install" is dishonest** without breaker bar + PB Blaster.
  - Some Honda/Toyota CUVs require muffler heat-shield trim or temporary muffler drop — must be in install notes (CURT 13555 on 07-11 CR-V is a known one).
  - **Tow rating ≠ vehicle capacity.** A Class 3 hitch on a Mazda CX-5 is rated 4,000 lb on the hitch, but the CX-5's max towing is 2,000 lb. PDPs MUST show "Hitch rating" AND "Vehicle max towing" separately or you'll get warranty/return claims when someone tries to tow 3k.
- **Return-rate landmine score:** **3/10** — low because hitches are forgiving, frame-bolt geometry is stable, and class differentiation is clean. Estimated returns: ~3% baseline (industry standard). $ impact per 1,000 orders @ ~$185 AOV with class-3 mix = ~$5,500 in returns, mostly cosmetic damage in shipping (not fitment).
- **Stehlen-branded subset:** **10 SKUs** (4% of category). 7 are legitimate "Stehlen" private-label hitches on niche/late-model platforms where CURT doesn't have a part yet (Mazda CX-5, CX-9, Cadillac XT5, Mitsubishi Outlander PHEV, Nissan Rogue Sport, Honda Odyssey 18+, Jeep Grand Cherokee L 21+) — **this is the right private-label play: white-space platforms**. Plus 3 universal accessories (cargo carrier, hitch step). The vendor field is **inconsistent**: 7 say "Stehlen", 3 say "Stehlen Auto", they should be unified to `Stehlen Auto`.
- **3 specific FIX RECOMMENDATIONS for cycle 3+:**
  1. **Move 4-5 universal accessories** (`curt-2-loaded-ball-mount-with-1-7-8-ball-45034`, both hitch-step universals, the Stehlen cargo carrier, and the RV adjustable) to a `towing accessories` productType. They pollute YMM filters because they have no make/model.
  2. **Add `hitch_max_tongue_weight_lb` and `vehicle_max_towing_lb` as Shopify metafields** and render BOTH on PDP. Don't let buyers assume the hitch class = the vehicle's tow capacity.
  3. **Unify vendor field** — collapse {Stehlen, Stehlen Auto, CURT, Curt} to canonical strings. Currently you have "CURT" (135) + "Curt" (8) — that's 8 SKUs invisible to a vendor=CURT filter.

## 2. front grille

- **Total SKUs:** 166
- **Tagging integrity:** **Concern** — Year/make/model tagging is consistent, but **style is encoded only in the title**, not in dedicated tags. Mesh = 48 in titles, Honeycomb = 14, Vertical = 15, Horizontal = 9. Color is in titles too: Matte Black (74), Black (44), Chrome (38), Silver (5), Gloss Black (1). **No tag like `style:mesh` or `finish:chrome`** — that means filtering on the collection page will require regex on title or rebuilding the data layer.
- **Sub-model gating required:** **trim** — and this category is the **biggest trim-gate failure risk** in the audit. Modern grilles are NOT trim-agnostic. F-150 XLT vs Lariat vs King Ranch vs Limited each have different bezel geometry, badge cut-out (Ford oval position differs on Limited), and chrome-trim vs body-color rings. Same with Ram (Tradesman/Big Horn/Laramie/Limited/Rebel/TRX). The catalog has **only 2 Rebel mentions, 7 XL, 0 Raptor/Lariat/King Ranch/Limited/TRX/Laramie** in F-150/Ram grille titles.
- **Title-vs-tag mismatches found:**
  - `2010-2018-ram-2500-3500-4500-5500-big-horn-style-chrome-grille` — claims "Big Horn style", but Big Horn is a trim level on Ram **1500**; on 2500/3500/4500/5500 the equivalent is Lone Star, SLT, or Tradesman. The title is misleading. The grille is probably an aftermarket honeycomb-mesh in chrome — fine product, wrong descriptor.
  - `2013-2022-ram-1500-big-horn-style-front-grille-matte-black-abs` — same naming issue across an unrealistic 10-year span. Ram DT (19+) has a totally different headlight bezel and grille shell shape than Ram DS classic (13-18 + 19-23 classic). **A grille that fits 2013 DS will NOT fit 2019 DT.** This is a P0 fitment lie.
  - `2009-2012-dodge-ram-1500-mesh-style-front-grille-black` (Stehlen-branded) — fine, that's all DS gen 4.
  - `2007-2014-cadillac-escalade-diamond-mesh-front-grille-matte-black` — Escalade GMT900 (07-14) is one chassis, OK.
  - `1994-2002-dodge-ram-1500-2500-3500-front-grille-black` — actually OK; 2nd-gen Ram (94-01) and 3rd-gen Ram (02-08) DO have different grilles, but the listing says ends 2002 and 2002 is the last 2nd-gen year for 1500, so this is borderline. Verify whether the grille fits 2002 (last yr of 2nd-gen, sport pkg) or 2002 3rd-gen.
  - `2007-2014-gmc-yukon-yukon-xl-front-grille-chrome` — Yukon Denali 07-14 has a unique honeycomb chrome grille that aftermarket parts don't always match. The Denali sub-model isn't called out.
  - **Light-bar grille variants are only 3 SKUs** (Charger, F-150 21-23, Tundra 22-24) — this is a **massive missed assortment opportunity** because light-bar-ready grilles are 4x the margin of plain mesh grilles.
- **Install-copy honesty risks:** "Direct bolt-on" claim breaks down when (a) factory grille has a forward camera mount (Ford 360-cam on Lariat+) — the aftermarket grille often has no camera cutout; (b) ACC radar is mounted behind the lower grille on EcoBoost F-150s 18+, and aftermarket lowers can confuse radar return; (c) trucks with adaptive cruise (Ram Limited 19+) need the radar emitter clear, and many "Big Horn style" mesh grilles block it. Stating "no modification required" is a **lie** for trim-equipped trucks.
- **Return-rate landmine score:** **7/10** — high. Grilles are visually-driven impulse buys, most customers don't know they have a forward camera, and the visual fitment delta between trims is huge. Estimated returns: 12-18% on F-150/Ram if trim isn't gated. $ impact per 1,000 grille orders @ ~$215 AOV = **$32,000+ in return-cost risk** (including return shipping on a ~25-lb item, restocking, and the buyer's frustration cost).
- **Stehlen-branded subset:** **4 SKUs** (Tahoe/Suburban/Avalanche 07-14, Silverado/Tahoe/Suburban 99-06, Silverado 1500 07-13, Ram 1500 09-12). All four are matte-black mesh-style on high-volume GM/Ram platforms. **Strategically right product set** (top-3 selling pickup platforms), but this is a tiny presence in a 166-SKU category — Stehlen should expand to F-150 13th/14th gen and Ram DT.
- **3 specific FIX RECOMMENDATIONS for cycle 3+:**
  1. **Add structured tags:** `style:mesh|honeycomb|billet|vertical|horizontal|light-bar-ready`, `finish:matte-black|gloss-black|chrome|body-color`, `has_camera_cutout:true|false`, `radar_compatible:true|false`. Without these, the collection page can't filter and the PDP can't truth-tell.
  2. **Split the "Big Horn Style" SKUs** that span Ram DS + DT into 2 separate listings. The 2013-2022 Ram 1500 listing must be 2013-2018 (DS) + a new 2019-2024 (DT) listing — different shell shape, different bumper interface.
  3. **Add a trim filter** (or at minimum a "Confirm your trim before ordering" PDP banner with photos of OEM grille per trim) on F-150 13/14 gen, Ram DS/DT, Silverado T1XX, Tundra 3rd gen, Tacoma 4th gen. Cycle 3 wireframe should explicitly include this.

## 3. headlights - led crystal style

- **Total SKUs:** 146
- **Tagging integrity:** **Bad** — This category has the worst data-integrity problem in the audit. There is **no halogen-vs-LED bulb-type tag, no harness-compatibility tag, no factory-LED-vehicle exclusion**. Every product is tagged `LED headlights` because the aftermarket housing has LED accent lighting (DRL, light bar, halo, sequential turn), but the actual low-beam/high-beam bulbs in 99% of these are **halogen H11/H13/9007/9006**. The category name `headlights - led crystal style` is misleading marketing copy that the data team has accepted as truth.
- **Sub-model gating required:** **factory bulb type (halogen vs HID vs LED) AND trim** — and this category currently has **neither**. The bulb type is critical because factory-LED-equipped vehicles have a CAN-bus that detects bulb load; installing a halogen-housing aftermarket replacement on a factory-LED truck triggers DTCs and may render the headlight inoperative until a load resistor is installed. Returns from this single failure mode run 8-15% on premium truck trims.
- **Title-vs-tag mismatches found:**
  - **P0 — `09-18-dodge-ram-chrome-crystal-headlights-w-led-light-bar`** title says "2009-2024 Dodge Ram", tags include `year:2019, 2020, 2021, 2022, 2023, 2024`. **Ram 1500 DT launched 2019.** It has a totally different headlight bezel (more aggressive sweep, integrated DRL) than DS classic. This headlight will NOT fit a 2019+ Ram 1500 DT. It WILL fit the "Ram 1500 Classic" (which Ram sold alongside DT in 19-24 as a price-leader, retaining DS sheet-metal). The product description must say "Fits 2009-2018 Ram 1500 AND 2019-2024 Ram 1500 **Classic only** — does NOT fit Ram 1500 DT". As-is, this is a guaranteed return on every 19+ DT order. **Conservative estimate: 30% of orders for this SKU at 2019+ years are DT, not Classic = ~$200 cost per wrong order × est. 60 orders/yr = $12,000/yr just on this one SKU.**
  - Same problem on `09-18-dodge-ram-crystal-headlights-w-led-light-bar-black`, `09-18-dodge-ram-chrome-crystal-headlights-sequential-led-turn-signal`, `09-18-dodge-ram-crystal-headlights-sequential-led-turn-signal-black`, `2009-2022-dodge-ram-crystal-headlights-chrome-quad-style`, `2009-2022-dodge-ram-crystal-black-headlights-quad-style` — **6 SKUs with the same lie**.
  - **P0 — `07-13-toyota-tundra-08-15-sequoia-chrome-led-crystal-headlights`** title says "2007-2017 Toyota Tundra & Sequoia". Tundra Limited 14-17 has factory **Quad-Beam LED** as standard. The aftermarket halogen-housing replacement won't accept the OEM LED connector and the DRL will not function. Also: 2014 was a **mid-cycle facelift** for Tundra — the headlight housing geometry changed (Tundra 14-21 is bigger, more sloped). Titles 07-13/07-17 spanning the facelift is a **fitment lie**. Same on `07-13-toyota-tundra-08-15-sequoia-led-crystal-headlights-black`, `07-13-toyota-tundra-08-15-sequoia-chrome-led-headlights-sequential`, `07-13-toyota-tundra-08-15-sequoia-led-crystal-headlights-black-1` (4 SKUs), and `07-13-toyota-tundra-08-17-sequoia-full-led-projector-headlights-black` (1 more = 5 total).
  - **P1 — `07-14-chevy-silverado-crystal-black-headlights-no-amber`** spans GMT900 (07-13) and K2XX (14). K2XX is a totally different chassis with different headlights. The 2014 model year Silverado is K2XX, NOT GMT900. **Title is wrong — should be 07-13.**
  - **P1 — `07-13-chevy-silverado-1500-08-14-2500-3500-led-crystal-headlights-chrome`** the date span is correct for HD (08-14 = GMT900 HD) and 1500 (07-13 = GMT900) — both are GMT900. This one is actually OK. Same for the JDMA black variant.
  - **P1 — `99-02-silverado-00-06-suburban-tahoe-led-headlights-bumper-lights-black`** title shows it knows the Silverado/Suburban year-split (99-02 vs 00-06). Better than the Tundra listings.
  - **All 9 F-150 04-08 + 09-14 listings** are accurate (those generations have stable headlight geometry, all-halogen factory). **2018-2020 F-150 listing** (`2018-2020-ford-f-150-full-led-projector-headlights-black-fr646`) crosses the P552 facelift (mid-2018). Fine for 18-20. **No 2021+ F-150 (P702 14th gen) listings — that's a coverage gap, not a lie.** The 21+ F-150 has factory LED on XLT+ trims with different harness; it would be hard to fit anyway.
- **Install-copy honesty risks:**
  - "Plug & play" — only 10 SKUs have this tag. **Most halogen-housing replacements on factory-LED vehicles need load resistors** (50W 6-ohm) wired in to prevent CAN-bus errors. PDP must say "Plug-and-play on factory halogen vehicles ONLY. Factory LED-equipped vehicles (Ram Limited 19+, Tundra Limited 14+, F-150 Lariat/Limited 18+) require a load resistor harness sold separately."
  - "Sequential turn signal" — works on 12V switched, fine in most cases. But Ram DS 09-18 has CAN-bus turn signal — sequentials can throw a "bulb out" warning on the dash unless flashed. Disclose this.
  - **Aiming legality:** DOT/SAE compliance is sketchy on most "JDM-style" aftermarket housings; some states (CA, NY) ticket for non-DOT lights. Customer return reason "headlights are too bright/blinding oncoming traffic" is the #2 reason for headlight returns — these housings often have no proper cutoff. **Disclose photometric pattern in PDP.**
- **Return-rate landmine score:** **8/10** — highest in the audit. Estimated returns at current data: 18-25% across the category, concentrated on Ram 19+ DT, Tundra 14+ Limited, F-150 18+ trim. $ impact per 1,000 orders @ ~$340 AOV = **$60,000+ in returns + freight + customer-trust damage** (headlights are a known "sketch-buy" category and returns also kill repeat purchases).
- **Stehlen-branded subset:** **1 SKU** — `88-98-chevy-c10-ck-crystal-headlights-w-led-bar-8pc-chrome-set` (1994-2000 Chevy C/K). One 8-piece set on a 25+ year old truck. **This is a non-existent Stehlen position in the headlight category.** Either (a) Stehlen should not private-label headlights at all because the liability is too high, or (b) Stehlen needs a rigorous QC + DOT-compliance program before expanding here. **Strong recommendation: do NOT expand Stehlen-branded headlights without DOT testing.**
- **3 specific FIX RECOMMENDATIONS for cycle 3+:**
  1. **Split every multi-generation headlight listing** at the actual chassis break: Ram 09-18 ≠ Ram DT 19+ ≠ Ram Classic 19-24; Tundra 07-13 ≠ Tundra 14-21 ≠ Tundra 22+; Silverado 07-13 ≠ Silverado K2XX 14-18 ≠ T1XX 19+; F-150 09-14 ≠ F-150 15-17 ≠ F-150 18-20 ≠ F-150 21+. **Estimated 11 SKUs need to be split into 22-25 SKUs.**
  2. **Add metafield `factory_headlight_type` enum (halogen | hid | led | matrix-led)** on the **vehicle** side, and `compatible_with_factory_type` on the part side. PDP shows: "Your 2020 Ram Limited has factory LED — this halogen-housing kit needs a load resistor (sold separately). Continue?"
  3. **Add a P0 PDP banner** on every halogen-housing listing that ANY year-range overlaps a factory-LED model: "Verify your 2018+ F-150 / 2014+ Tundra Limited / 2019+ Ram has HALOGEN headlights before ordering. Factory-LED trucks need a different harness." This is the single highest-leverage copy fix in the entire catalog.

## 4. tonneau cover - lock & roll up

- **Total SKUs:** 136
- **Tagging integrity:** **Pass — best in the audit.** Spot-check of 20 random titles: **20/20 disclose bed length** (5/5.5/5.7/5.8/6/6.2/6.4/6.5/8 ft). Tag analysis: **136/136 rows have a bed-length tag** in the tags column (`5 ft bed`, `5.5 ft`, `5.8 ft`, `6.4 ft`, `6.5 ft`, `8 ft`, `short bed`, `long bed`, `standard bed`). Year/make/model granularity is per-row (each model-year is its own tag). This is the gold standard for the catalog.
- **Sub-model gating required:** **bed_length (REQUIRED, P0)** — tonneau covers are the #1 return-rate landmine in pickup accessories. Bed-length data is here, but the **UI must ENFORCE bed-length selection at PDP**, not just display it. This is documented in `docs/reference/fitment_flow_decision.md` as the conditional 4th-filter use case.
- **Title-vs-tag mismatches found:**
  - **P0 — `09-22-ram-1500-2500-3500-roll-up-tonneau-cover-w-led-bed-lights`** Stehlen-branded, says "2009-2022 Dodge Ram 1500/2500/3500 6.4 ft Bed". Tags include 2019-2022 and `Ram 1500 Classic` — so they KNOW it's the classic. **But title doesn't say "Classic"** — a buyer with a 2020 Ram 1500 DT will see "fits 2020 Ram 1500" and order, and **the bed clamp geometry is different on DT vs DS Classic**. Same SKU is repeated as `02-08-dodge-ram-1500-6-5-bed-flush-roll-up-tonneau-cover-133304` and `2002-2009-dodge-ram-1500-2500-3500-6-5-bed-tonneau-cover` (5 Ram tonneau listings have similar Ram-1500-vs-Classic ambiguity). **High return risk on every Ram DT order.**
  - **P1 — `2007-2016-toyota-tundra-roll-up-tonneau-cover-w-led-bed-lights`** spans Tundra 2nd gen pre-facelift (07-13) and post-facelift (14-21). The bed dimensions are identical across the facelift (Tundra 2nd gen kept the same bed for 15 years), so the tonneau likely DOES fit. But there was a **mid-2014 bed-rail design tweak** on some trims (TRD Pro had different rail contour) — verify that the included clamps work on TRD Pro 14-17. Spot-check by VIN before assuming.
  - **`2014-2018-gmc-sierra-5-8-roll-up-tonneau-cover-w-led-bed-lights`** vs `2014-2019-gmc-sierra-6-5-roll-up-tonneau-cover-w-led-bed-lights` — note the year asymmetry (one ends 2018, other 2019). This actually correctly reflects K2XX (14-18) vs T1XX (19+) — Sierra K2XX has both 5'8" and 6'5" beds, but T1XX 19+ has 5'8" / 6'7" / 8'. The 6.5 listing extending to 2019 is because the 6'5" bed continued briefly into 19 model year overlap. **Borderline correct, verify the clamps fit 2019.**
  - **`02-22-dodge-ram-1500-2500-3500-6-5-bed-...`** — see bed-mat section. **Ram has no 6'5" bed** (it's 5'7", 6'4", 8'). Several Ram tonneau listings say "6.5 ft" when they mean 6'4" — minor labeling sloppiness, but at fitment time the clamp adjustment range usually accommodates. **Verify clamp travel before declaring fit.**
- **Install-copy honesty risks:**
  - "Easy install — under 30 min" — true for soft roll-ups on a clean bed rail. **Adds ~1 hr if existing bed liner has lip protrusions** (Line-X over-rail on most truck owners' beds). Disclose: "If you have an over-rail bed liner, plan for additional 30-60 min — clamps mount under the rail."
  - "Weather-tight" — vinyl roll-ups leak in heavy rain at the front bulkhead seam. Honest copy: "Sheds light rain. Heavy rain may seep at front seal — wipe bed dry after long storms." Returns drop ~20% with this disclosure.
  - "Lifetime warranty" on vinyl — covers seam failure, NOT UV fade or torn material. State exclusions on PDP, not buried.
- **Return-rate landmine score:** **5/10 with current data, would be 9/10 without bed-length tagging.** Bed-length data is solid; the residual risk is Ram DS-vs-DT and Sierra K2XX-vs-T1XX confusion. With proper UI gating + 3 SKU splits, drops to 3-4%. $ impact per 1,000 orders @ ~$185 AOV = **$11,000-$17,000 in returns at current state**, dropping to **~$6,000** with fixes.
- **Stehlen-branded subset:** **41 SKUs (30% of category)** — by far the largest Stehlen private-label position in the catalog. This is the strategic anchor. The Stehlen tonneau line covers the highest-volume pickup platforms (Colorado/Canyon, Silverado/Sierra, F-150, Ram, Tundra, Tacoma, Frontier, Titan, Ranger). **This is the highest-margin, most-defensible part of the entire catalog — protect it ferociously.** Quality complaints on Stehlen tonneaus will hurt the brand more than any other category.
- **3 specific FIX RECOMMENDATIONS for cycle 3+:**
  1. **Hard-gate bed_length at PDP** — block Add-to-Cart until customer confirms bed length on every tonneau (and persist to garage so they're never asked twice). This is already in the architecture spec — make sure cycle 3 implements it, not punts it.
  2. **Split Ram listings at the DS/DT boundary** even when the bed dimension nominally matches, because the bed-rail clamp geometry differs (DT has a redesigned bedside top rail). Add an explicit "Ram DT 2019+" vs "Ram Classic" listing pair for the 6.4 ft / 5.7 ft beds.
  3. **Add `over_rail_liner_compatible: true|false|with_modification`** as a tag, and surface it on PDP. ~40% of pickup owners have an over-rail spray-in or drop-in liner; current copy doesn't address them.

## 5. truck bed mat - rubber

- **Total SKUs:** 133
- **Tagging integrity:** **Pass with 2 contamination cases** — 131/133 rows have bed-length info (in title and tags). The 2 outliers are SUV trunk mats miscategorized: `2018-2024-chevy-equinox-hex-style-rubber-trunk-mat-black-1pc` and `2018-2024-chevy-traverse-hex-style-rubber-trunk-mat-black-1pc`. These are CARGO MATS, not bed mats, and one is Stehlen-branded. **Move both to a `cargo mats - rubber` productType.**
- **Sub-model gating required:** **bed_length (REQUIRED, P0) AND fleetside-vs-stepside on legacy GM trucks** — 6 listings have "Fleetside" or "Stepside" in title (correct), but the rest don't. Modern trucks are universally fleetside, so this is only relevant pre-2007 GM, pre-2008 Ford, pre-2002 Ram. Where it matters, the data IS there.
- **Title-vs-tag mismatches found:**
  - **P0 — `02-22-dodge-ram-1500-2500-3500-6-5-bed-pvc-truck-bed-mat`** and `02-22-dodge-ram-1500-2500-3500-6-5-ft-rubber-bed-mat-v2` and `02-22-dodge-ram-1500-2500-3500-6-5-ft-bed-mat-w-rambox` (3 SKUs): **Ram has NO 6.5 ft bed.** Ram 1500 bed lengths are 5'7" (67"), 6'4" (76"), and 8' (97"). The "6.5 ft Ram" listings are either (a) legacy data from an old supplier sheet that mis-rounded 6'4" to 6.5 ft, or (b) actually a 6'4" mat with a sloppy label. Either way, **a customer with a 2020 Ram Big Horn (6'4" bed) sees "6.5 ft" and may think theirs is "6.4 ft" and skip the listing — losing a sale**, OR a customer with a different bed buys it expecting 6.5 ft and gets 6'4" actual — return. **Audit the actual product dimensions and re-label as 6.4 ft.**
  - **P0 — `02-22-dodge-ram-1500-2500-3500-...` (12+ SKUs spanning 2002-2022 Ram 1500/2500/3500)** — Dodge Ram 1500 had 4 chassis generations in this span (DR/DH 02-08, DS 09-18, DT 19-current, DT Classic 19-24 alongside DT). Bed lengths are nominally consistent BUT bed liner / D-ring / RamBox configurations differ. The 5.7 ft RamBox-only mats are correctly called out (4 SKUs). The non-RamBox 5.7 / 6.4 / 8 ft mats spanning 02-22 should be **verified for tie-down / cargo-rail interference** on each chassis gen. Likely OK for non-RamBox, but flag for QC.
  - **P1 — `97-00-chevy-gmc-c-k-truck-6-5ft-bed-rubber-mat-lightweight-v2`** — 1997-2000 C/K Truck. The 1999 was a transition year (introduced GMT800 Silverado) but C/K nameplate continued through 1999 on HD. This is borderline — verify whether the mat fits 1999 C/K HD (the long bed would be 8 ft, not 6.5 ft, on the HD).
  - **`02-22-dodge-ram-rubber-bed-mat-57-rambox-grey`** — RamBox-only variant, correctly labeled. Good.
  - **`2007-2021-toyota-tundra-5-5-bed-rubber-truck-bed-mat-grey`** title says "5.5", description in column 2 says **5.6 ft** — actual Tundra 2nd-gen short bed is **5'7" (66.7" / 5.56 ft)**. Round to 5.5 in marketing or 5.6 in tech specs, but be **consistent**. Mismatch within the same row.
- **Install-copy honesty risks:**
  - "Cuts to fit" / "trim to fit" — true for universal mats; not needed on these custom-fit V2 mats. Good.
  - "Won't slip" — depends on bed surface. On spray-in liners, rubber mats DO slip. PDPs should say: "Designed for OEM bed surface. Spray-in or drop-in liner buyers: a thin grip-tape kit (not included) may be needed."
  - "Easy clean — hose down" — true. Honest.
  - "100% waterproof" — true for rubber, but water can pool under the mat and rust the bed. Honest copy: "Lift mat occasionally to dry the bed, especially after long winters." Reduces "rust developed under mat" return reason.
  - **EV truck mats with frunk** (Lightning, Hummer EV pickup, R1T) are a unique opportunity — 3 listings each. Make sure the frunk dimensions are accurate for each model year — the Hummer EV frunk is shallower than R1T's.
- **Return-rate landmine score:** **3/10** — bed mats are forgiving. Wrong bed length ships flat, customer notices immediately, returns easily. Estimated returns: 4-5% with current data (mostly from the 6.5-ft-Ram label confusion). $ impact per 1,000 orders @ ~$95 AOV = ~$3,500. Drops to 2-3% with the Ram bed-length relabel.
- **Stehlen-branded subset:** **29 SKUs (22% of category)** — second-largest private-label position after tonneaus. Strong coverage of all major pickup platforms (Silverado/Sierra all gens, F-150 all gens, Ram all gens, Tundra, Tacoma, Frontier, Ranger, Lightning EV, Gladiator). The "V2" naming convention is consistent. **Stehlen bed mats + Stehlen tonneaus = 70 SKUs and the brand's defensible moat.**
- **3 specific FIX RECOMMENDATIONS for cycle 3+:**
  1. **Re-measure and re-label all "Ram 6.5 ft" bed mats to "6.4 ft" or "6 ft 4 in"** to match Ram's actual bed nomenclature. This is a 30-min data fix that eliminates a real source of cart abandonment AND wrong-bed returns.
  2. **Move the 2 Equinox/Traverse trunk mats out** to a `cargo mats - rubber` productType. Better category UX, also opens an SUV cargo-mat assortment opportunity (Stehlen could private-label more).
  3. **Add `bed_floor_type` metafield** (`oem_steel | spray_in | drop_in`) and surface "Best for OEM bed; grip-tape kit recommended for liners" on PDP. Reduces the "mat slips" return reason which is currently ~1.5% of bed-mat returns industry-wide.
